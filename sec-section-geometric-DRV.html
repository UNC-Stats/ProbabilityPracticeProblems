    1. Discrete Distributions: Password Guessing Logistics.

    A new secretary has been given \(27\) computer passwords, only one of which will permit access to a secure computer file. Because the secretary has no idea which password is correct, he chooses one of the passwords at random and tries it. If it does not work, he puts it back in with the other passwords before randomly selecting the next password to try (not a very clever secretary!).
    🔗
    (a)
    Let the random variable \(Y\) represent the total number of tries required to successfully access the file. This scenario is modeled using a geometric random variable. Which of the following best explains why the geometric model is appropriate here?
    🔗
    • Because we are counting the number of independent, identical trials required to achieve the very first success, and the probability of success remains constant on each attempt due to replacement.
    • Correct! A geometric random variable specifically tracks the number of independent trials up to and including the first success. Because the secretary replaces the incorrect passwords back into the pool, the trials are independent and the probability of success remains a constant \(p = \frac{1}{27}\) each time.
    • Because there are exactly two outcomes (success or failure) per guess, and the process is restricted to a fixed, predetermined maximum ceiling of 27 total attempts.
    • Incorrect. A fixed number of trials \(n\) describes a Binomial distribution. In this geometric scenario, the secretary has no set limit and will keep guessing indefinitely until they finally hit the correct password.
    • Because we are sampling from a small, finite pool of passwords, which causes the probability of success to change dynamically after each incorrect attempt.
    • Incorrect. If the secretary threw away incorrect passwords (sampling without replacement), the probability would change, requiring a Hypergeometric distribution. Because he puts them back, the probability does not change.
    • Because we are calculating the continuous average rate of server logins across a fixed interval of time.
    • Incorrect. Tracking arrivals over a continuous interval describes a Poisson or Exponential process, not a series of distinct, separate button-press trials.
    🔗
    (b)
    Specify the probability distribution function (or probability mass function) for your random variable \(Y\text{.}\)
    🔗
    • \(P(Y = y) = \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y-1}\)
    • Correct! Since there is only \(1\) correct password out of \(27\text{,}\) the constant probability of success on each independent trial is \(p = \frac{1}{27}\text{.}\) The probability of a failed attempt is \(1 - p = \frac{26}{27}\text{.}\) Substituting these into the formula for a geometric random variable, we get the probability it takes \(y\) total tries is:
      \begin{equation*} P(Y = y) = \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y-1} \end{equation*}
    • \(P(Y = y) = \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y}\)
    • \(P(Y=y)=\choose{27,y} \left(\frac{1}{27}\right)^y\left(\frac{26}{27}\right)^{27-y}\)
    • \(P(Y=y)=\choose{27,y} \left(\frac{1}{27}\right)^y\left(\frac{26}{27}\right)^{27-y}\)

    Calculate the mean \(E(Y)\) and standard deviation \(\sigma_Y\) for the trial number on which the correct password is first identified.
    🔗
    • \(E(Y) = 27\) and \(\sigma_Y \approx 26.5\)
    • Correct! For a geometric distribution, the expected value is \(E(Y) = \frac{1}{p} = \frac{1}{1/27} = 27\text{.}\) The variance is \(V(Y) = \frac{1-p}{p^2} = \frac{26/27}{(1/27)^2} = 26 \times 27 = 702\text{.}\) Taking the square root gives the standard deviation: \(\sigma_Y = \sqrt{702} \approx 26.495\text{,}\) which rounds to \(26.5\text{.}\)
    • \(E(Y) = 26\) and \(\sigma_Y \approx 26.5\)
    • Incorrect! This gives the expected number of failures, instead of the expected number of trials.
    • \(E(Y) = 13.5\) and \(\sigma_Y \approx 3.7\)
    • Incorrect. This treats the process as if it were sampling without replacement, splitting the mid-point of the stack. Because of duplicate guesses, the true mean wait time is longer.
    • \(E(Y) = 27\) and \(\sigma_Y = 702.0\)
    • Incorrect. The value \(702\) is the population variance \(V(Y)\text{.}\) You must take the square root of the variance to find the standard deviation metric.
    • \(E(Y) = 1.0\) and \(\sigma_Y \approx 0.98\)
    • Incorrect. This uses the success probability parameters directly rather than inverting the fractions into tracking averages.
    Hint.
    Use the geometric formulas: \(E(Y) = \frac{1}{p}+1\) and \(V(Y) = \frac{1-p}{p^2}\text{.}\) Once you calculate the variance value, take its square root to isolate the standard deviation \(\sigma_Y\text{.}\)
