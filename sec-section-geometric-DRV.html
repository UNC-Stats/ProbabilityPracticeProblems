    Section 5.3 Geometric Random Variable

    By completing the problems provided below, you will gain experience with the Geometric random variable. Specifically, you will practice:
    • Identifying when the Geometric distribution can be used to model a scenario.
      🔗
      🔗
    • Using the Geometric probability distribution function to compute probabilities.
      🔗
      🔗
    • Using the expected value and variance formulas for a Geometric random variable.
      🔗
      🔗
    • Using the moment generating function to derive the expected value and variance formulas for a Geometric random variable.
      🔗
      🔗
    🔗

    1. Is this Geometric?

    A group of friends is playing a tabletop strategy game. According to the game rules, rolling a standard six-sided die and landing on a \(6\) grants a player a special “bonus action” token, which can be used at any point in the game. An example of a bonus action would be drawing cards from a deck of 50 resource cards, which contains exactly 5 rare “Gold” cards and exactly 8 “Action” cards.
    🔗
    Below you are presented with multiple random variables related to this scenario. Select all that can be be considered Geometric/can be modeled with a Geometric distribution.
    🔗
    • The total number of times a player must roll the die until they successfully roll their first \(6\text{.}\)
    • Correct! Each die roll is independent, the probability of rolling a \(6\) remains constant at \(p = \frac{1}{6}\text{,}\) and the random variable counts the total rolls needed to achieve the first success.
    • The total number of \(6\)’s a player rolls during a single turn where they roll the die 7 times.
    • Incorrect. This counts the number of successes within a predetermined, fixed number of trials (\(n = 10\)). This is modeled by a Binomial distribution.
    • A player draws cards, one-by-one, from the resource deck until they find a Gold card. They do not put cards back after drawing.
    • Incorrect. Because the player draws cards without replacement, the probability of drawing a Gold card changes with every single card removed. Therefore, trials are dependent.
    • A game mechanic requires a player to draw a card from the resource deck, check if it is an Event card, and then shuffle it back into the deck if it is not. The variable is the number of cards drawn to find the first Event card.
    • Correct! Shuffling the card back into the deck ensures that the trials remain completely independent with a constant probability. This counts the number of failures before the first success, which is Geometric.
    • The total number of turns the group plays until a the third "bonus action" token is claimed.
    • Incorrect. Here we are waiting for more than one success to occur, which means we should use a Negative Binomial distribution, rather than a Geometric distribution.
    Hint.
    To determine if a variable fits the geometric model, check if it satisfies the following assumptions:
    🔗
    • Binary - Are there exactly two complementary outcomes for each trial (e.g., Success vs. Failure)? Bernoulli trials!
      🔗
      🔗
    • Independent - Does the outcome of one trial have no effect on the outcome of another?
      🔗
      🔗
    • Constant Probability of Success - Does the probability (\(p\)) stay constant for every single trial?
      🔗
      🔗
    • Stop After First Success - Does the variable count the trials or attempts required until the very first success occurs (with the trials stopping at that point)?
      🔗
      🔗

    2. Password Guessing.

    A new secretary has been given \(27\) computer passwords, only one of which will permit access to a secure computer file. Because the secretary has no idea which password is correct, he chooses one of the passwords at random and tries it. If it does not work, he puts it back in with the other passwords before randomly selecting the next password to try (not a very clever secretary!).
    🔗
    Let the random variable \(Y\) represent the total number of tries required to successfully access the file. This scenario is modeled using a geometric random variable.
    🔗

    (a)

    Specify the probability distribution function for your random variable \(Y\text{.}\)
    🔗
    • \(P(Y = y) = \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y-1}\)
    • Correct! Since there is only \(1\) correct password out of \(27\text{,}\) the constant probability of success on each independent trial is \(p = \frac{1}{27}\text{.}\) The probability of a failed attempt is \(1 - p = \frac{26}{27}\text{.}\) Substituting these into the formula for a geometric random variable, we get:
      \begin{equation*} P(Y = y) = \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y-1} \end{equation*}
    • \(P(Y = y) = \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y}\)
    • Incorrect. This function computes the probability that there are \(y\) failures before the correct password is found.
    • \(P(Y=y)=\binom{27}{y} \left(\frac{1}{27}\right)^y\left(\frac{26}{27}\right)^{27-y}\)
    • Incorrect. This is the formula for Binomial probabilities. It is computing the chance of finding the correct password \(y\) times during 27 attempts.
    • \(P(Y=y)=\binom{27}{y} \left(\frac{1}{27}\right)\left(\frac{26}{27}\right)^{y-1}\)
    • Incorrect. The combination \(\binom{27}{y}\) is unnecessary here. There is only one way to obtain the first success on the trial \(y\text{.}\)
    • \(P(Y=y)= \left(\frac{26}{27}\right) \left(\frac{1}{27}\right)^{y-1}\)
    • Incorrect. The probability and success and failure are reversed here!
    🔗

    (b)

    🔗

    (c)

    Calculate the mean \(E(Y)\) and standard deviation \(\sigma_Y\) for the trial number on which the correct password is first identified.
    🔗
    • \(E(Y) = 27\) and \(\sigma_Y \approx 26.5\)
    • Correct! For a geometric distribution, the expected value is \(E(Y) = \frac{1}{p} = \frac{1}{1/27} = 27\text{.}\) The variance is \(V(Y) = \frac{1-p}{p^2} = \frac{26/27}{(1/27)^2} = 702\text{.}\) Taking the square root gives the standard deviation: \(\sigma_Y = \sqrt{702} \approx 26.495\text{,}\) which rounds to \(26.5\text{.}\)
    • \(E(Y) = 26\) and \(\sigma_Y \approx 26.5\)
    • Incorrect! This gives the expected number of failures, instead of the expected number of trials.
    • \(E(Y) = 26\) and \(\sigma_Y \approx 5.10\)
    • Incorrect. This gives the expected number of failures, instead of the expected number of trials, and represents a calculation error for the standard deviation.
    • \(E(Y) = 27\) and \(\sigma_Y = 702.0\)
    • Incorrect. The value \(702\) is the population variance \(V(Y)\text{.}\) You must take the square root of the variance to find the standard deviation metric.
    • \(E(Y) = 27\) and \(\sigma_Y \approx 5.10\)
    • Incorrect. Most likely you forgot to square the denominator when computing the variance.
    🔗

    (d)

    Which of the following best explains why the geometric model was appropriate here?
    🔗
    • Because we are counting the number of independent trials required to achieve the very first success, and the probability of success remains constant on each attempt due to replacement.
    • Correct!
    • Because there are exactly two outcomes (success or failure) per guess, and the process is restricted to a fixed, predetermined maximum ceiling of 27 total attempts.
    • Incorrect. A fixed number of trials \(n\) describes a Binomial distribution. In this scenario, the secretary has no set limit and will keep guessing indefinitely until they finally hit the correct password.
    • Because we are sampling from a small, finite pool of passwords, which causes the probability of success to change dynamically after each incorrect attempt.
    • Incorrect. If the secretary threw away incorrect passwords (sampling without replacement), the probability would change, possibly making the Hypergeometric distribution appropriate. Because he puts them back, the probability does not change.
    • Because we are calculating the average rate of logins across an interval of time.
    • Incorrect. Tracking the average rate of logins over a continuous interval might describes a Poisson process, but not a geometric one.
    • Because the secretary put the password back after each attempt.
    • This is partially correct. It is important that the password be put back so that trials are independent (with a constant chance of success), but it does not fully explain why the scenario is geometric.

    3. The Pastry Chef’s Dilemma.

    Baking French macarons is notoriously difficult due to temperature and humidity variables. Suppose that an amateur baker plans to keep baking batches of macarons until they achieve their very first perfect bake. Assuming batches are independent and that the baker has a constant success probability of \(p = 0.25\text{,}\) answer the questions that follow.
    🔗

    (a)

    Let \(Y\) represent the total number of batches baked in this scenario. What is the probability that the baker achieves their first perfect batch of macarons on their 3rd attempt?
    🔗
    • 0.2500
    • Incorrect. This is the probability of succeeding on the very first batch, \(P(Y = 1)\text{.}\)
    • 0.1406
    • Correct! The first two batches must fail while the third is a success:
      \begin{equation*} P(Y = 3) = (0.75)^2 \times 0.25 = 0.140625\text{.} \end{equation*}
    • 0.1055
    • Incorrect. It looks like you calculated the probability of failing 3 times before succeeding, instead of only failing twice.
    • 0.1875
    • Incorrect. It looks like you calculated the probability of succeeding on the second try instead of the third.
    • 0.0469
    • Incorrect. Make sure you are using \(p=0.25\) as the probability for baking a perfect batch (success).
    🔗

    (b)

    Calculate the probability that it takes the baker more than 4 attempts to achieve their first perfect batch, \(P(Y > 4)\text{.}\)
    🔗
    • 0.6836
    • Incorrect. This is the complementary probability that they succeed within the first 4 attempts (\(P(Y \le 4)\)).
    • 0.0791
    • Incorrect. This is the probability of succeeding on the 5th attempt specifically, not the probability of taking more than 4 attempts.
    • 0.3164
    • Correct! Using the complement rule:
      \begin{equation*} P(Y > 4) = 1-P(Y \le 4) = 1-[P(Y=1)+P(Y=2)+P(Y=3)+P(Y=4)]\text{,} \end{equation*}
      where \(P(Y = y) = (0.25)(0.75)^{y-1} \)
    • 0.5781
    • Incorrect. This is the probability that it takes less than 4 attempts, not more than 4.
    • 0.4219
    • Incorrect. This is the probability that it takes 4 or more attempts, not strictly more than 4.
    🔗

    (c)

    🔗

    (d)

    Suppose the baker has already failed on their first 5 batches. Given this frustrating history, what is the conditional probability that they will require more than 2 additional attempts in order to finally get a perfect batch?
    🔗
    • 0.1336
    • Incorrect. This is the unconditioned probability that it takes more than 7 attempts, \(P(Y > 7)\text{.}\)
    • 0.2374
    • Incorrect. This is the probability of what we were given, that it takes more than 5 attempts, \(P(Y > 5)\text{.}\)
    • 0.0445
    • Incorrect. This is the unconditional probability that it takes exactly 2 more attempts, \(P(Y=7)\text{.}\)
    • 0.5625
    • Correct! Due to the memoryless property, the distribution "forgets" the 5 initial failures. The probability of needing more than 2 additional trials given 5 initial failures is identical to the probability of needing more than 2 trials from the very start: \(P(Y > 5 + 2 \mid Y > 5) = P(Y > 2) = 0.5625\text{.}\)
    • 0.1874
    • Incorrect. This is the probability that it takes exactly 2 more attempts (Y=7), given the first 5 were failures. We want to know the probability that it will take more than 2 additional attempts.
    Hint.
    You are given the information that the baker has failed on their first 5 batches, which means the first success will come some time after batch 5 (\(Y>5\)). You are therefore computing the conditional probability: \(P(Y \gt 7|Y \gt 5)\text{.}\)
    🔗
    Use the memoryless property of the geometric random variable to help simplify the calculations!

    1. Expected Value and Variance [Derivation 1].

    Let \(Y\) be a discrete geometric random variable representing the total number of trials required to achieve the first success, with a constant success probability \(p\text{.}\) The moment generating function for \(Y\) was shown to be:
    \begin{equation*} M_Y(t) = E(e^{tY})=\dfrac{pe^s}{1-qe^s}\text{.} \end{equation*}
    🔗

    (a)

    Use the moment generating function to show that the expected value of \(Y\) is \(E(Y)=1/p\text{.}\)
    🔗
    🔗

    (b)

    Use the moment generating function to show that the variance of \(Y\) is \(V(Y)=q/p^2\text{.}\)
    🔗
    🔗
    🔗

    2. Expected Value and Variance [Derivation 2].

    Refer to the previous problem. There’s an easier way to use the moment generating function to find \(E(Y)\) and \(V(Y)\text{!}\)
    🔗
    Let \(h_Y(s)=ln\left[M_Y(s)\right]\text{.}\) The function \(h_Y(s)\) has the following helpful properties:
    \begin{equation*} h'_Y(0)=E(Y) \end{equation*}
    and
    \begin{equation*} h''_Y(0)=V(Y)\text{.} \end{equation*}
    🔗
    You will use these properties to re-derive the expected value and variance for \(Y\text{.}\)
    🔗

    (a)

    First, find \(h_Y(s)\text{.}\) In other words, take the natural log of the moment generating function, and then simplify as much as you can using the properties of logs.
    🔗
    🔗

    (b)

    Use \(h_Y(s)\) to show that the expected value of \(Y\) is \(E(Y)=1/p\text{.}\) [Take the first derivative of \(h_Y(s)\text{,}\) and then plug in \(s=0\text{.}\)]
    🔗
    🔗

    (c)

    Use \(h_Y(s)\) to show that the variance of \(Y\) is \(V(Y)=q/p^2\text{.}\) [Take the second derivative of \(h_Y(s)\text{,}\) and then plug in \(s=0\text{.}\)]
