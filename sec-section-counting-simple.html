    1. Distinct Die Rolls.

    A standard 6-sided die is rolled 5 times in a row. Find the probability that all 5 numbers rolled are completely different from one another.
    🔗
    (a)
    First determine the appropriate counting technique that should be used, and then compute the total number of outcomes where all 5 rolls yield different values.
    🔗
    • \(6^5 = 7,776\)
    • Incorrect. Using the Multiplication Principle like this calculates the size of the sample space of all possible die roll sequences.
    • \(_6P_5 = 720\)
    • Correct! Since the 5 rolled numbers must all be distinct, the order matters and repetition is not allowed. Therefore, we can a permutation. Specifically, we want to know how many 5-permutations of the six numbers on the die are possible.
    • \(\binom{6}{5} = 6\)
    • Incorrect. This is a combination, which ignores the rolling sequence order. Order matters here, because rolling 1, 2, 3, 4, 5 is a completely different sequential outcome than rolling 5, 4, 3, 2, 1.
    • \(5^6 = 15,625\)
    • Incorrect. Here the Multiplication Principle is being used to try to compute the size of the sample space of all possible die roll sequences, but the numbers have been plugged in wrong!
    • \(5! = 120\)
    • Incorrect. This only counts how many ways 5 numbers can be arranged. It does not take into account that there are 6 possible numbers that can be rolled each time.

    2. Korean BBQ.

    Your professor went to Suh Sushi Korean BBQ in Fort Collins, CO for Valentine’s Day. The restaurant offered a special where a couple could choose one appetizer, two entrees, one dessert, and two drinks.
    🔗
    (a)
    How many different shared dinners were available if a couple could choose between six appetizers, fourteen entrees, three desserts, and three drinks.
    🔗
    • \(31,752 \)
    • Correct! One appetizer, two entrees, one dessert, and two drinks gives us
      \begin{equation*} 6\cdot 14 \cdot 14\cdot3 \cdot3 \cdot3 =31752 \text{ dinner options.} \end{equation*}

    • Incorrect. Likely mistake - Make sure each person gets a drink and entree while counting.
    • \(19,656 \)
    • Incorrect. Likely mistake - Are there any rules saying the couple has to order different items from each other?
    • \(571,536 \)
    • Incorrect. Likely mistake - This answer includes ordering too many items. Check the special again.

    3. Committee Seating Arrangements.

    Eight committee members are meeting in a room that has twelve chairs.
    🔗
    (a)
    In how many ways can the group choose which \(8\) chairs will be occupied, if we do not care yet who sits in which chair?
    🔗
    • \(\binom{12}{8} = 495\) ways
    • Correct! Since the arrangement or order in which people sit does not matter, we use a combination.
    • \(_{12}P_8 = 19,958,400\) ways
    • Incorrect. This counts the number of ways to assign specific people to specific chairs, but order does not matter here.
    • \(12 \times 8 = 96\) ways
    • Incorrect. This answer applies the multiplication rule incorrectly.
    • \(8! = 40,320\) ways
    • Incorrect. This is the number of ways to arrange the 8 people in 8 chairs, but order does not matter here. Also, this answer does not account for the fact that we have to choose 8 chairs from the available 12.
    🔗
    (b)
    In how many ways distinct ways can the \(8\) committee members actually sit down in the \(12\) available chairs?
    🔗
    • \(_{12}P_8 = 19,958,400\) ways
    • Correct! Order matters here, so we use a permutation.
    • \(\binom{12}{8} = 495\) ways
    • Incorrect. This only selects which chairs are used, it does not take seating order into account.
    • \(12^8 = 429,981,696\) ways
    • Incorrect. This would allow multiple committee members to sit in the same chair!
    • \(8! = 40,320\) ways
    • Incorrect. This is the number of ways to arrange the 8 people in 8 chairs, but it does not account for the fact that we have to choose 8 chairs from the available 12.
    🔗

    4. 5-by-6 Array.

    Thirty items are arranged in a 5-by-6 array as shown below. Calculate the number of ways to form a set of three distinct items such that no two of the selected items come from the same row or column.
    🔗
    • \(1,200 \)
    • Correct! For the first item, we have 30 options to select from. For the second item we have only 20 options, since we have to remove all items that were in the same row and column as the first item. Similarly, there are only 12 options for item 3. However, the calculation \(30\cdot 20\cdot 12\) takes into account the order of the items. So, we need to divide by \(3!\) to get the number of unique sets of three items.
    • \(1,575 \)
    • Incorrect. Likely mistake - Did you remove enough options after the first and second item selection? No two items can come from the same row or column.
    • \(4,060 \)
    • Incorrect. Likely mistake - No two of the selected items can come from the same row or column.
    • \(2,000 \)
    • Incorrect. Likely mistake - Make sure all items come from different rows and columns.
    • \(7,200 \)
    • Incorrect. Likely mistake - This answer treats a selection such as A1 A15 A29 as different from A29 A15 A1, when they are actually the same set of chosen items.
    Hint.
    Does order matter here?

    Using your answers from parts (a) and (b), determine the probability that the student can solve all five of the problems on her probability exam.
    🔗
    • \(\frac{1}{42} \approx 0.0238\)
    • Correct! Divide the number of favorable exams by the total number of possible exams:
      \begin{equation*} P(X = 5) = \frac{\binom{6}{5}}{\binom{10}{5}} = \frac{6}{252} = \frac{1}{42} \approx 0.0238\text{.} \end{equation*}
    • \(\frac{1}{252} \approx 0.0040\)
    • Incorrect. Check the numerator! There is more than one favorable exam. The denominator is correct.
    • \(\frac{6}{10} \approx 0.6000\)
    • Incorrect. This would be the probability that, for the first and only problem on the exam, the instructor selects one of the six problems that the student can answer.
    • \(\frac{5}{6} \approx 0.8333\)
    • Incorrect. This answer is just the ratio of exam questions to the number of questions the student can answer, which is not what we want.
