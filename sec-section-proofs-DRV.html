    1. Property of Expectation.

    Let \(Y=aX+b\) be a linear transformation of random variable \(X\text{,}\) where \(a\) and \(b\) are constants. Then,
    \begin{equation*} E(Y)=E(aX + b) = aE(X) + b\text{.} \end{equation*}

E(aX + b) = \sum_{x} (ax + b)P(X = x)

    2. The Variance Shortcut Formula.

    The variance of a random variable \(X\) measures the expected value of the squared deviations around its mean, \(\mu = E(X)\text{.}\) Thus, the formula for variance can be written as:
    \begin{equation*} V(X) = E\left[(X - E(X))^2\right] = E\left[(X - \mu)^2\right] \end{equation*}
    Prove that, from this definition, we can derive the following variance shortcut formula:
    \begin{equation*} V(X) = E(X^2) - [E(X)]^2 = E(X^2) - \mu^2 \end{equation*}
    🔗
    Arrange the blocks below in the correct logical sequence. You may or may not use all blocks.
    🔗
    

    By definition:
    

    
\begin{equation*}
V(X)  = E\left[(X - \mu)^2\right] 
\end{equation*}

    

    
---


    

    Expand the perfect square polynomial inside the expectation brackets:
    

    
\begin{equation*}
\implies V(X) = E\left[X^2 - 2\mu X + \mu^2\right]
\end{equation*}

    

    
---


    

    Apply the linearity property of expectations to split the expression into three terms:
    

    
\begin{equation*}
\implies V(X)  = E(X^2) - E(2\mu X) + E(\mu^2)
\end{equation*}

    

    
---


    

    Apply the linearity property of expectations to handle the constant terms and simplify the expression:
    

    
\begin{equation*}
\implies V(X)  = E(X^2) - 2\mu E(X) + \mu^2
\end{equation*}

    

    
---


    

    Substitute the identity \(E(X) = \mu\) into the linear expression:
    

    
\begin{equation*}
\implies V(X) = E(X^2) - 2\mu(\mu) + \mu^2 
\end{equation*}

    

    
---


    

    Combine like terms:
    

    
\begin{equation*}
\implies V(X) = E(X^2) - 2\mu^2 + \mu^2 = E(X^2) - \mu^2
\end{equation*}
    🔗

    3. MGF of a Sum of Independent Variables.

    Let \(Y = X_1 + X_2 + \dots + X_n\text{,}\) where the \(X_i\)’s are mutually independent random variables. Prove the multiplicative property for moment generating functions:
    \begin{equation*} M_Y(s) = M_{X_1}(s) \cdot M_{X_2}(s) \dots M_{X_n}(s) \end{equation*}
    🔗
    Arrange the blocks below in the correct logical sequence. You will use all blocks. Start with the definition of a moment generating function.
    🔗
    

    By definition:
    

    
\begin{equation*}
M_Y(s) = E\left[e^{sY}\right]
\end{equation*}

    

    
---


    

    Substitute \(Y = X_1 + X_2 + \dots + X_n\text{:}\)

    

    
\begin{equation*}
\implies M_Y(s) = E\left[e^{s(X_1 + X_2 + \dots + X_n)}\right]
\end{equation*}

    

    
---


    

    Distribute the \(s\text{:}\)

    

    
\begin{equation*}
\implies M_Y(s)  = E\left[e^{sX_1 + sX_2 + \dots + sX_n}\right]
\end{equation*}

    

    
---


    

    Apply laws of exponents:
    

    
\begin{equation*}
\implies M_Y(s)  = E\left[e^{sX_1} \cdot e^{sX_2} \dots e^{sX_n}\right]
\end{equation*}

    

    
---


    

    Apply the expectation property for independent random variables:
    

    
\begin{equation*}
\implies M_Y(s)  = E\left[e^{sX_1}\right] \cdot E\left[e^{sX_2}\right] \dots E\left[e^{sX_n}\right]
\end{equation*}

    

    
---


    

    We can now rewrite the expression as:
    

    
\begin{equation*}
\implies M_Y(s) = M_{X_1}(s) \cdot M_{X_2}(s) \dots M_{X_n}(s),
\end{equation*}

    

    since \(M_{X_i}(s) = E\left[e^{sX_i}\right]\) (by definition).
    Hint.
    After using exponent laws to write the expression as a product of exponentials, you must apply the special expectation property that is only valid when variables are explicitly given as independent.

    Let \(Y=aX+b\) be a linear transformation of random variable \(X\text{,}\) where \(a\) and \(b\) are constants. Then,
    \begin{equation*} V(Y)=V(aX + b) = a^2V(X) \text{.} \end{equation*}
    Prove that this property is true.

    2. MGF of a Linear Transformation of a Random Variable.

    Let \(X\) be a random variable with moment generating function \(M_X(s)\text{,}\) and let \(a\) and \(b\) be constant scalars. Prove the linear transformation property for moment generating functions:
    \begin{equation*} M_{aX+b}(s) = e^{bs}M_X(as) \end{equation*}
    🔗
    Hint.
    Start with the definition of a moment generating function, \(M_Z(s) = E\left[e^{sZ}\right]\text{,}\) substituting \(Z = aX + b\text{.}\)
