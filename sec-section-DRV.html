    A backend system developer constructs a discrete probability distribution for the daily demand for a specific cloud-hosted premium AI API script. Let the random variable \(Y\) represent the number of daily execution blocks, measured in hundreds of calls (so \(Y = 1\) means 100 calls, \(Y = 2\) means 200 calls, etc.):
    • \(P(Y = 0) = 0.1\) (0 calls are made)
      🔗
      🔗
    • \(P(Y = 1) = 0.3\) (100 calls are made)
      🔗
      🔗
    • \(P(Y = 2) = 0.4\) (200 calls are made)
      🔗
      🔗
    • \(P(Y = 3) = 0.2\) (300 calls are made)
      🔗
      🔗
    🔗
    (a)
    Find the moment generating function \(M_Y(s)\) for the random variable \(Y\text{.}\)
    🔗
    • \(M_Y(s) = 0.1 + 0.3e^s + 0.4e^{2s} + 0.2e^{3s}\)
    • Correct! By definition, the MGF of a discrete random variable is \(M_Y(s) = E[e^{sY}] = \sum e^{sy} \cdot P(Y = y)\text{.}\) Substituting our weights yields \(0.1e^{0} + 0.3e^{1s} + 0.4e^{2s} + 0.2e^{3s} = 0.1 + 0.3e^s + 0.4e^{2s} + 0.2e^{3s}\text{.}\)
    • \(M_Y(s) = 0.1e^s + 0.3e^{2s} + 0.4e^{3s} + 0.2e^{4s}\)
    • Incorrect. This shifts the values of the support array forward by 1 index point instead of matching them directly to the exponents of \(e\text{.}\)
    • \(M_Y(s) = 1.7e^s\)
    • Incorrect. This looks like you tried to use the expected value \(E(Y) = 1.7\) directly inside a single exponent. The MGF must preserve the individual probabilities as distinct exponential coefficients.
    • \(M_Y(s) = 0.1 + 0.3s + 0.4s^2 + 0.2s^3\)
    • Incorrect. This is the structural format for a standard probability generating function (PGF) rather than a moment generating function (MGF), which requires the base Euler variable \(e\text{.}\)
    • \(M_Y(s) = 0.2 + 0.4e^s + 0.3e^{2s} + 0.1e^{3s}\)
    • Incorrect. This reverses the order of the probability weights, assigning the higher probabilities to the wrong values of the support array.
    🔗
    (b)
    The platform bills the developer at a basic linear rate of \(\$0.10\) per single API execution, which equates to a flat cost of \(\$10\) per unit block of 100 calls. Find the moment generating function \(M_C(s)\) for the daily operational cost \(C = 10Y\text{.}\)
    🔗
    • \(M_C(s) = 0.1 + 0.3e^{10s} + 0.4e^{20s} + 0.2e^{30s}\)
    • Correct! For a linear transformation scaling a random variable by a constant \(k\text{,}\) the scaling identity states that \(M_{kY}(s) = M_Y(ks)\text{.}\) Substituting \(10s\) into our function from Part 1 transforms \(e^s \to e^{10s}\text{,}\) \(e^{2s} \to e^{20s}\text{,}\) and \(e^{3s} \to e^{30s}\text{.}\)
    • \(M_C(s) = 1.0 + 3.0e^s + 4.0e^{2s} + 2.0e^{3s}\)
    • Incorrect. This scales the outer probability weights by 10 instead of mapping the transformation multiplier inside the structural exponents.
    • \(M_C(s) = 10 \cdot (0.1 + 0.3e^s + 0.4e^{2s} + 0.2e^{3s})\)
    • Incorrect. Multiplying the entire MGF by 10 implies an expansion of the total probability area out of unity, which breaks foundational scaling rules.
    • \(M_C(s) = 0.1 + 0.3e^{s+10} + 0.4e^{2s+10} + 0.2e^{3s+10}\)
    • Incorrect. Adding 10 to the exponent is the rule for translating a random variable by a constant addition (\(Y + 10\)), not scaling it by a multiplier product (\(10Y\)).
    • \(M_C(s) = 0.1 + 0.3e^{10s} + 0.4e^{100s} + 0.2e^{1000s}\)
    • Incorrect. This squares or cubes the multiplier scaling factor inside the exponent instead of keeping the constant linear scaling factor of 10 intact across all tasks.
    🔗

    Suppose the cloud host updates their enterprise billing plan to a nonlinear structure. The developer pays a fixed baseline fee of \(\$5\) per day, plus a variable optimization surcharge that tracks quadratically with execution volume, modeled as \(2Y^2\text{.}\) The total daily cost is given by the random variable:
    \begin{equation*} Z = 5 + 2Y^2 \end{equation*}
    🔗
    Utilize the derivative properties of the moment generating function to compute the expected daily cost under this updated plan, \(E(Z)\text{.}\)
    🔗
    • \(\$12.40\)
    • Correct! By linearity of expectation, \(E(Z) = 5 + 2E(Y^2)\text{.}\) Differentiating the base MGF twice yields \(M_Y''(s) = 0.3e^s + 1.6e^{2s} + 1.8e^{3s}\text{.}\) Evaluating at zero gives the second raw moment: \(E(Y^2) = M_Y''(0) = 0.3 + 1.6 + 1.8 = 3.7\text{.}\) Plugging this back in yields \(E(Z) = 5 + 2(3.7) = 12.40\text{.}\)
    • \(\$10.78\)
    • Incorrect. This occurs if you evaluate the square of the linear mean instead of using the second moment, computing \(5 + 2[E(Y)]^2 = 5 + 2(1.7)^2 = 10.78\text{.}\) Remember that for nonlinear models, \(E(Y^2) \neq [E(Y)]^2\text{.}\)
    • \(\$7.40\)
    • Incorrect. You successfully determined the variable surcharge component \(2E(Y^2) = 2(3.7) = 7.40\text{,}\) but you forgot to add the fixed daily baseline subscription fee of \(\$5\text{.}\)
    • \(\$8.70\)
    • Incorrect. This happens if you find the raw second moment \(E(Y^2) = 3.7\) and add the fixed fee of \(\$5\) directly, forgetting to multiply the variable term by its scalar coefficient of 2.
    • \(\$3.70\)
    • Incorrect. This value is only the raw second moment \(E(Y^2) = M_Y''(0) = 3.7\text{.}\) You must evaluate this value through the complete transformation function \(5 + 2E(Y^2)\text{.}\)
    Hint.
    By linearity of expectation, you can split up the expression: \(E(5 + 2Y^2) = 5 + 2E(Y^2)\text{.}\) Recall that the second raw moment of a random variable is found by evaluating the second derivative of its MGF at zero: \(E(Y^2) = M_Y''(0)\text{.}\) Differentiate \(M_Y(s)\) twice with respect to \(s\text{,}\) plug in \(s = 0\text{,}\) and finish the arithmetic.
    🔗
    🔗
    Solution.
    To evaluate the expected value of the nonlinear pricing model \(Z = 5 + 2Y^2\text{,}\) we invoke the linearity property of expectations:
    \begin{equation*} E(Z) = E(5 + 2Y^2) = 5 + 2E(Y^2) \end{equation*}
    🔗
    1. Find the second raw moment \(E(Y^2)\) by taking the second derivative of the given demand MGF, \(M_Y(s) = 0.1 + 0.3e^s + 0.4e^{2s} + 0.2e^{3s}\text{:}\)
    \begin{equation*} M_Y'(s) = 0.3e^s + 0.8e^{2s} + 0.6e^{3s} \end{equation*}
    \begin{equation*} M_Y''(s) = 0.3e^s + 1.6e^{2s} + 1.8e^{3s} \end{equation*}
    🔗
    2. Evaluate \(M_Y''(0)\) by substituting \(s = 0\) to solve for the second moment:
    \begin{equation*} E(Y^2) = M_Y''(0) = 0.3e^0 + 1.6e^0 + 1.8e^0 = 0.3 + 1.6 + 1.8 = 3.7 \end{equation*}
    🔗
    3. Substitute \(E(Y^2) = 3.7\) back into our linear expectation equation to calculate the total expected daily cost:
    \begin{equation*} E(Z) = 5 + 2(3.7) = 5 + 7.4 = 12.4 \end{equation*}
    Under the quadratic pricing system, the expected daily server bill is \(\$12.40\text{.}\)

      🔗

    • \(0.02\)
    • \(P(X = 3)\text{,}\) the probability that a unit chosen at random has exactly three rooms.
    • \(0.05\)
    • \(P(4 \le X \le 6)\text{,}\) the probability that a unit has between four and six rooms.
    • \(0.83\)
    • \(P(X \neq 10)\text{,}\) the probability that a unit chosen at random is not a 10-room unit.
    • \(0.98\)
    • \(P( X \le 6)\text{,}\) the probability that a unit at most six rooms.
    • \(0.88\)

    • \(0.04\)
    • \(0.63\)
    • \(0.92\)
    • \(0\)
    Solution.
    Mathematical Solutions from the CDF Graph:
    • \(P(X = 10) = 0.02\text{:}\) This point value is the vertical jump at the final step \(x = 10\text{.}\) Reading the graph values: \(F(10) - F(9) = 1.00 - 0.98 = 0.02\text{.}\)
      🔗
      🔗
    • \(P(X = 3) = 0.05\text{:}\) This represents the initial jump height where the step function first leaves zero at \(x = 3\text{,}\) which maps directly to \(F(3) - F(2) = 0.05 - 0.00 = 0.05\text{.}\)
      🔗
      🔗
    • \(P(4 \le X \le 6) = 0.83\text{:}\) To find the probability inside an integer interval using a CDF, subtract the baseline value just below the lower bound from the upper bound height:
      \begin{equation*} P(4 \le X \le 6) = F(6) - F(3) = 0.88 - 0.05 = 0.83 \end{equation*}

      🔗
      🔗
    • \(P(X \neq 10) = 0.98\text{:}\) Using the complement rule:
      \begin{equation*} P(X \neq 10) = 1 - P(X = 10) = 1 - 0.02 = 0.98 \end{equation*}
      Notice that this is also equal to \(P(X \le 9) = F(9) = 0.98\text{.}\)

    🔗
    Suppose a student web server is randomly selected from those audited in the county. We define the discrete random variable \(X\) to be the total number of security vulnerabilities found on that server.
    🔗
    (a)
    Find the probability distribution (Probability Mass Function) for the random variable \(X\) and sketch a graph of the resulting distribution.
    🔗
    🔗
    (b)
    Find the cumulative distribution function (CDF) for the random variable \(X\text{,}\) defined as \(F_X(x) = P(X \le x)\text{,}\) and sketch a graph of the resulting distribution.

    🔗
    (c)
    Compute the expected number of vulnerabilities, \(E(X)\text{.}\)
    🔗
    Solution.

    The expected number of configuration vulnerabilities per server is \(0.90\text{.}\)

    3. Discrete Distributions: Server Security Audits - Part 2.

    Refer to the previous problem. During a campus hackathon, the computer science department audited student web servers for two critical security configuration vulnerabilities. The automated scanner found that \(20\%\) of the student servers had neither vulnerability, \(40\%\) had Vulnerability A, and \(50\%\) had Vulnerability B (and of course, some had both tracking vulnerabilities).
    🔗
    Suppose a student web server is randomly selected from those audited in the county. We define the discrete random variable \(X\) to be the total number of security vulnerabilities found on that server.
    🔗
    (a)
    Find the moment generating function (MGF) for random variable \(X\text{.}\)
    🔗
    Solution.
    \begin{equation*} M_X (s)=0.2+0.7e^s+0.1e^{2s} \end{equation*}
    🔗
    🔗
    🔗
    (b)
    Use the MGF to recompute the expected number of impurities. Recall:
    \begin{equation*} M_X^{(k)} (0)=E(X^k) \end{equation*}
    🔗
    Solution.
    \begin{equation*} E(X)=M_X^{'} (0)=0.7e^0+0.2e^{2(0)}=0.90 \end{equation*}
    🔗
    🔗
    🔗
    (c)
    Use the moment generating function to recompute the variance for the expected number of impurities. You’ll need to use the MGF to find the second moment, and then apply the variance short-cut formula.
    🔗
    Solution.
    \begin{equation*} E(X^2 )=M_X^{''} (0)=0.7e^0+0.4e^{2(0)} =1.1 \implies V(X)=0.29 \end{equation*}
