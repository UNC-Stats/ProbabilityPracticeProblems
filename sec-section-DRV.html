The probability distribution of \(Y\) is given in the table below:

    Calculate the probability that a randomly chosen software portfolio piece features a commercial patent lifespan of at least 8 years; that is, find \(P(Y \ge 8)\text{.}\)
    🔗
    • \(0.20\)
    • Incorrect. This is only the isolated probability of exactly 8 years: \(P(Y = 8)\text{.}\) The phrase “at least 8” requires including all outcomes greater than or equal to 8.

    3. API Call Demands.

    A backend system developer constructs a discrete probability distribution (see below) for the daily demand for a specific cloud-hosted premium API script. Let the random variable \(Y\) represent the number of daily execution blocks, measured in hundreds of calls (e.g., \(Y = 2\) means 200 calls).
    🔗
    • \(P(Y = 0) = 0.1\) (0 calls are made)
      🔗
      🔗
    • \(P(Y = 1) = 0.3\) (100 calls are made)
      🔗
      🔗
    • \(P(Y = 2) = 0.4\) (200 calls are made)
      🔗
      🔗
    • \(P(Y = 3) = 0.2\) (300 calls are made)
      🔗
      🔗

    (a)

    Find the moment generating function \(M_Y(s)\) for the random variable \(Y\text{.}\)
    🔗
    • \(M_Y(s) = 0.1 + 0.3e^s + 0.4e^{2s} + 0.2e^{3s}\)
    • Correct! Using the MGF definition: \(M_Y(s) = E[e^{sY}] = \sum e^{sy} \cdot P(Y = y)=0.1e^{0} + 0.3e^{1s} + 0.4e^{2s} + 0.2e^{3s} = 0.1 + 0.3e^s + 0.4e^{2s} + 0.2e^{3s}\text{.}\)
    • \(M_Y(s) = 0.1e^s + 0.3e^{2s} + 0.4e^{3s} + 0.2e^{4s}\)
    • Incorrect. This shifts the values of \(Y\) forward by 1. See the hint for the MGF definition.
    • \(M_Y(s) = 1.7e^s\)
    • Incorrect. This looks like you took the expected value of \(Y\text{,}\) \(E(Y) = 1.7\text{,}\) and multiplied it by \(e^{s}\text{.}\) See the hint for the MGF definition.
    • \(M_Y(s) = 0.3e^s + 0.4e^{2s} + 0.2e^{3s}\)
    • Incorrect. Be careful! \(e^0\) equals one, not zero. See the hint for the MGF definition.
    • \(M_Y(s) = 0.2 + 0.4e^s + 0.3e^{2s} + 0.1e^{3s}\)
    • Incorrect. This reverses the order of the probabilities, assigning the higher probabilities to the lower values of \(Y\text{.}\) See the hint for the MGF definition.
    Hint.
    By definition, the MGF of a discrete random variable is
    \begin{equation*} M_Y(s) = E[e^{sY}] = \sum e^{sy} \cdot P(Y = y)\text{.} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    The platform bills the developer at a basic linear rate of \(\$0.10\) per single API execution, which equates to a flat cost of \(\$10\) per unit block of 100 calls. Find the moment generating function, \(M_C(s)\text{,}\) for the daily operational cost \(C = 10Y\text{.}\)
    🔗
    • \(M_C(s) = 0.1 + 0.3e^{10s} + 0.4e^{20s} + 0.2e^{30s}\)
    • Correct! For a linear transformation, such as scaling a random variable by a constant \(k\text{,}\) we have the property: \(M_{kY}(s) = M_Y(ks)\text{.}\) Substituting \(10s\) into our MGF for \(s\) transforms \(e^s \to e^{10s}\text{,}\) \(e^{2s} \to e^{20s}\text{,}\) and \(e^{3s} \to e^{30s}\text{.}\)
    • \(M_C(s) = 0.1 + 0.3e^{s} + 0.4e^{2s} + 0.2e^{3s}\)
    • Incorrect. This is the MGF for \(Y\text{,}\) not \(10Y\text{.}\)
    • \(M_C(s) = 1 + 3e^s + 4e^{2s} + 2e^{3s}\)
    • Incorrect. We can not just multiply the MGF by 10.
    • \(M_C(s) = 0.1e^{10s} + 0.3e^{11s} + 0.4e^{12s} + 0.2e^{13s}\)
    • Incorrect. Adding \(10s\) to the exponent is the MGF property to use when transforming a random variable by adding a constant (\(Y + 10\)), not multiplying by a constant (\(10Y\)).
    • \(M_C(s) = 0.1e^{s} + 0.3e^{10s} + 0.4e^{20s} + 0.2e^{30s}\)
    • Incorrect. \(0.1e^{s(10\cdot 0)} \neq 0.1e^s\text{.}\)
    🔗

    (c)

    Hint.
    The first derivative of the moment generating function evaluated at \(s=0\) gives the first moment: \(E(C) = M_C'(0)\text{.}\)

    Hint.
    The second derivative of the moment generating function evaluated at \(s = 0\) gives the second moment: \(E(C^2) = M_C''(0)\text{.}\)
