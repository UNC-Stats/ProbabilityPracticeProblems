    1. Continuous Distributions: Recognizing Beta Kernels.

    The relative humidity \(Y\) measured at a specialized weather station has a probability density function (PDF) given by:
    \begin{equation*} f(y) = k y^3 (1-y)^5, \quad \text{for } 0 \le y \le 1\text{,} \end{equation*}
    where \(k\) is a proportionality constant.
    🔗
    Hint: Do NOT integrate!
    🔗
    (a)
    🔗
    (b)
    Compute the expected relative humidity, \(E(Y)\text{.}\)
    🔗
    • \(E(Y) = 0.500\)
    • Incorrect. A mean of 0.500 implies a perfectly symmetric distribution curve. Because the right-hand failure parameter exponent (\(\beta = 6\)) is larger than the left-hand success parameter exponent (\(\alpha = 4\)), the density mass is skewed downward, pulling the center of gravity below the midpoint.
    • \(E(Y) = 0.400\)
    • Correct! For any valid continuous random variable following a standard Beta distribution, we can skip tedious calculus integration by leveraging the algebraic distribution shortcut formulas for its moments:
      \begin{equation*} E(Y) = \frac{\alpha}{\alpha + \beta} \end{equation*}
      Substituting our verified parameters from Part A (\(\alpha = 4\) and \(\beta = 6\)) maps directly to the targeted long-run balance point:
      \begin{equation*} E(Y) = \frac{4}{4 + 6} = \frac{4}{10} = 0.400 \end{equation*}
      The expected relative humidity at this location is exactly 0.400 (or 40%).
    • \(E(Y) = 0.600\)
    • Incorrect. This looks like a parameter calculation inversion where you set the numerator to the wrong parameter (\(\frac{\beta}{\alpha+\beta}\)). Because \(\beta \gt \alpha\text{,}\) the distribution leans left, making the mean smaller than 0.500.
    • \(E(Y) = 0.667\)
    • Incorrect. This distractor evaluates the ratio \(\frac{\beta}{\alpha}\) or \(\frac{4}{6}\text{.}\) The denominator for a Beta distribution mean must capture the total combined weight of both shapes, \(\alpha + \beta\text{.}\)

    2. Continuous Distributions: Beta Modeling of Cloud Cache Workloads.

    An enterprise cloud computing data center manages massive data buffers that are completely cleared and reset every Monday morning. System architecture engineers monitor the proportion, \(Y\text{,}\) of this high-speed cache storage capacity that is actively utilized during the weekly data sync cycle. Over many months of operational logging, engineers establish that \(Y\) behaves as a continuous random variable that can be modeled by a Beta distribution with shape parameters \(\alpha = 4\) and \(\beta = 2\text{.}\)
    🔗
    Complete the questions below to evaluate the system’s infrastructure storage risks.
    🔗
    (a)
    Which of the following expressions defines the correct Probability Density Function (PDF), \(f(y)\text{,}\) over the domain support interval \(0 \le y \le 1\text{?}\)
    🔗
    • \(f(y) = 4y^3(1-y)\)
    • Incorrect. This option uses the shape parameter value \(\alpha = 4\) directly as the constant multiplier coefficient. To find the correct scalar constant, you must calculate the reciprocal of the Beta function pool, \(\frac{1}{\text{B}(\alpha, \beta)}\text{.}\)
    • \(f(y) = 20y^3(1-y)\)
    • Correct! The standard algebraic profile for a Beta distribution PDF is defined as:
      \begin{equation*} f(y) = \frac{1}{\text{B}(\alpha, \beta)} y^{\alpha - 1} (1-y)^{\beta - 1} \end{equation*}
      Substituting our given parameters (\(\alpha = 4\) and \(\beta = 2\)) maps to the functional components as follows:
      • The variable powers drop by 1: \(\alpha - 1 = 3\) and \(\beta - 1 = 1\text{,}\) giving the polynomial kernel \(y^3(1-y)\text{.}\)
      • The normalizing scalar constant multiplier utilizes Gamma factorial identities for positive integers:
        \begin{equation*} k = \frac{1}{\text{B}(4, 2)} = \frac{\Gamma(4+2)}{\Gamma(4)\cdot\Gamma(2)} = \frac{5!}{3! \cdot 1!} = \frac{120}{6 \cdot 1} = 20 \end{equation*}
      Multiplying the parts together gives the valid PDF expression: \(20y^3(1-y)\text{.}\)
    • \(f(y) = 5y^4(1-y)\)
    • Incorrect. It looks like you forgot to subtract 1 from the exponents when mapping the shape parameters to the polynomial variable components, setting the kernel up as \(y^{\alpha}(1-y)^{\beta-1}\) instead of \(y^{\alpha-1}(1-y)^{\beta-1}\text{.}\)
    • \(f(y) = \frac{1}{20}y^3(1-y)\)
    • Incorrect. This options uses the raw Beta integral value \(\text{B}(4,2) = \frac{1}{20}\) directly as the multiplier. Remember that the constant outside the kernel must be the reciprocal of that value to ensure the entire area under the curve sums to exactly 1.00.
    • \(f(y) = 20y^4(1-y)^2\)
    • Incorrect. While the constant multiplier 20 is correct, the variable exponents were not adjusted downward by 1, which alters the core structural shape of the distribution.
    🔗
    (b)
    🔗
    (c)
    Find the general expression for the cumulative distribution function (CDF), \(F(y) = P(Y \le y)\text{,}\) for the active cache capacity interval \(0 \le y \le 1\text{.}\)
    🔗
    • \(F(y) = 20y^3 - 20y^4\)
    • Incorrect. This is the raw probability density function (PDF) with the terms expanded, \(20(y^3 - y^4)\text{.}\) To find the cumulative function, you must take the anti-derivative integral of this expression.
    • \(F(y) = 5y^4 - 4y^5\)
    • Correct! To derive the continuous cumulative distribution function, integrate the valid PDF expression from Part A from the absolute lower boundary limit 0 up to an arbitrary variable value point \(y\text{:}\)
      \begin{align*} F(y) \amp = \int_{0}^{y} 20t^3(1-t) \, dt = 20 \int_{0}^{y} (t^3 - t^4) \, dt\\ \amp = 20 \left[ \frac{t^4}{4} - \frac{t^5}{5} \right]_{0}^{y} = 5y^4 - 4y^5 \end{align*}
      Evaluating this function at the absolute upper domain limit confirms its validity: \(F(1) = 5(1)^4 - 4(1)^5 = 1\text{.}\)
    • \(F(y) = 4y^5 - 5y^4\)
    • Incorrect. This looks like an algebraic sign direction error made during the polynomial integration step. Review the subtraction balance when taking the anti-derivative of the negative term.
    • \(F(y) = \frac{5}{4}y^4 - \frac{4}{5}y^5\)
    • Incorrect. It looks like you divided by the integration powers but forgot to distribute the constant multiplier coefficient coefficient of 20 to clear out the fractional denominators.
